# Recherches et POC

Analyses comparatives, expérimentations et preuves de concept **sans valeur de décision officielle**.

Toute recherche doit indiquer la question, les hypothèses, les résultats, les limites et, si nécessaire, les sources. Si une décision structurante en découle, rédiger une [ADR](../decisions/README.md) et la faire approuver selon la politique prévue. Une recherche terminée n'implique jamais qu'une solution a été adoptée.
